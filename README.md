# Слово за словом

Картки для англійської. Працює без AI й без акаунта Claude: один файл `index.html`, дані на пристрої (localStorage) + копія в Google-таблиці.

- Версії коду: історія комітів цього репозиторію.
- Версії даних: Google-таблиця → Файл → Історія версій. Лист «Слова» і «Прогрес» — читабельна копія.
- Налаштування таблиці: вставити `apps-script.gs` у Розширення → Apps Script, Deploy → Web app (Execute as: Me, Access: Anyone), адресу `…/exec` вписати в Налаштування → Google-таблиця.
- Іконка: Safari → Поділитися → «На початковий екран».
